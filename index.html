Import / Export

Direkt från innebandy.se

stats.innebandy.se använder ett signerat API som webbläsaren inte kan anropa direkt, så lagets JSON hämtas med projektets befintliga hämtare (tools/fetch-team.js, samma som ib-schedule-overlap.rb använder). Klistra in lagets länk, t.ex. https://stats.innebandy.se/sasong/44/lag/116542/spelprogram:

Välj sedan filen seasons_SÄSONG_teams_LAG.json (eller en cachad cache/schedule/team_*.json). Truppen (namn, nummer, position) uppdateras och kommande matcher dyker upp under fliken Matcher.

Trupp från Excel/CSV

Kolumner: Namn, Nummer, Position (MV/B/C/F), Reserv (t.ex. "C,F"). Befintliga spelare med samma namn uppdateras.

Närvaro från Excel/CSV (t.ex. SportAdmin-export)

Kolumner: Namn + Totalt och/eller Vecka. Matchas mot namn i truppen (skiftlägesokänsligt). Procent ("85 %") fungerar också.

Backup (JSON)

JS-API för integration (konsolen eller ett bokmärke): LagAPI.getState(), LagAPI.setState(obj), LagAPI.importSquad([{namn,nummer,position,reserv}]), LagAPI.importAttendance([{namn,totalt,vecka}]), LagAPI.select().

Delning via GitHub (krypterat)

Engångsinställning. Datan krypteras med lösenordet och sparas i ett privat repo. Token (fine-grained, bara Contents: read and write på datarepot) krypteras också med lösenordet och laddas ner som token.enc, som läggs bredvid index.html i appens repo. Inget sparas i klartext.
